File 02

Statements

Fifteen witnesses on writing code. One of them is pinned at the top; the rest are tied together.

大多数优秀的程序员从事编程工作，不是因为期望获得报酬或得到公众的称赞，而是因为编程是件有趣的事儿。

Most good programmers do programming not because they expect to get paid or get adulation by the public, but because it is fun to program.

林纳斯·托瓦兹Linus Torvalds Attributed

函数应该做一件事。做好这件事。只能做这一件事。

Functions should do one thing. They should do it well. They should do it only.

罗伯特·C. 马丁Robert C. Martin Clean Code, 2008

理论上，理论和实践没有区别。但实践上，是有区别的。

In theory, there is no difference between theory and practice. But, in practice, there is.

简·范德斯奈普特Jan L. A. van de Snepscheut Attributed

我坚信，自我教育是唯一的教育形式。

I hold that self-education is the only kind of education there is.

艾萨克·阿西莫夫Isaac Asimov Attributed

练习成就不了完美。多练习会产生髓磷脂，是髓磷脂让你做到完美。

Practice doesn't make perfect. Practice makes myelin, and myelin makes perfect.

丹尼尔·科伊尔Daniel Coyle The Talent Code, 2009

优良设计创造价值的速度，快于其增加成本的速度。

Good design adds value faster than it adds cost.

托马斯·C. 盖勒Thomas C. Gale Attributed

视代码如诗词，勿要做无谓的堆砌。

Treat code like poetry; don't pile it up for no reason.

伊利亚·多尔曼Ilya Dorman Attributed

All problems in computer science can be solved by another level of indirection.

计算机科学中的所有问题，都可以通过再加一层间接性来解决。

David J. Wheeler Attributed — often quoted by Butler Lampson

Don't repeat yourself. Every piece of knowledge must have a single, unambiguous, authoritative representation within a system.

不要重复自己。系统中的每一份知识，都应当有单一、明确、权威的表示。

Andrew Hunt & David Thomas The Pragmatic Programmer, 1999

代码写得越急，程序跑得越慢。

The more hurriedly code is written, the more slowly the program runs.

Roy Carlson Attributed

你用英语都写不出来的东西，就别指望用代码写了。

If you can't write it in English, don't expect to write it in code.

Peter Halpern Attributed

我这个人走得很慢，但是我从不后退。

I am a slow walker, but I never walk back.

亚伯拉罕·林肯Abraham Lincoln Attributed

失败也是我需要的，它和成功对我一样有价值。

Failure is also what I need; it is as valuable to me as success.

托马斯·爱迪生Thomas A. Edison Attributed

善于利用零星时间的人，才会做出更大的成绩来。

Only those who use their odd moments of time well will achieve greater things.

华罗庚Hua Luogeng Attributed

写代码时，每次都要告诉自己：最后负责维护代码的，会是一个知道你住在哪的变态暴力狂。

Always code as if the person who maintains your code is a violent psychopath who knows where you live.

约翰·伍德John Woods Attributed
